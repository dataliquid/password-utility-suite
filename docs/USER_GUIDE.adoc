== Overview

Password Utility Suite is a Java Swing application for encrypting and decrypting sensitive values in YAML and Properties configuration files. It supports multiple encryption algorithms and environments, making it ideal for managing secrets across different deployment stages (development, staging, production).

== Quick Start

=== Starting the Application

[source,bash]
----
mvn exec:java -Prun
----

Or run the fat JAR:

[source,bash]
----
java -jar password-utility-suite-1.0.0-SNAPSHOT.jar
----

== Setting Up an Environment

Before you can encrypt or decrypt values, you need to configure at least one environment with a master password.

=== Opening the Environments Dialog

.Figure 2: Environments Dialog

=== Creating a New Environment

1. Enter an **Environment Name** (e.g., "Production", "Development")
2. Enter a **Master Password** - this is the key for encryption/decryption
3. Optionally adjust the **Default Algorithm** (default: AES-256-GCM)
4. Optionally customize **Format Prefix/Suffix** (default: `ENC[` and `]`)
5. Click **Save** (Alt+S)

== Encrypting Values

=== Method 1: Double-Click

1. Select an entry in the tree
2. Double-click on it to toggle encryption/decryption

=== Method 2: Keyboard Shortcut

1. Select an entry in the tree
2. Press `Alt+C` to toggle encryption/decryption

=== Method 3: Context Menu

1. Right-click on an entry in the tree
2. Select "Toggle Encrypt/Decrypt"

After encryption, the value in the editor changes to the encrypted format:

.Figure 6: Encrypted password value
image::06-encrypted-value.png[Encrypted Value,width=800]

|2
|**Encrypted value in Tree** - Shows with lock icon prefix in the tree view
|===

The encrypted value is wrapped in the configured format (e.g., `ENC[...]`).

== Decrypting Values

To decrypt a value, use the same methods as encryption:
* Double-click on an encrypted entry
* Select it and press `Alt+C`
* Right-click and select "Toggle Encrypt/Decrypt"

IMPORTANT: You must have the same environment (with the correct master password) active that was used for encryption.

== Working with Multiple Environments

You can create multiple environments for different purposes:

* **Development**: Uses a simple password for local testing
* **Staging**: Uses the staging environment's master password
* **Production**: Uses the production master password

Each environment can have:
* Different master passwords
* Different encryption algorithms
* Different format prefixes/suffixes

=== Switching Environments

Select the desired environment from the dropdown in the Action Panel. The application will:

1. Update the active encryption settings
2. Re-parse the file to detect encrypted values with the new format
3. Show encrypted values with a lock icon in the tree

== Working with Multiple Tabs

The application supports multiple open files in tabs:

* Each tab maintains its own editor content
* Each tab can have a different selected environment
* Each tab can have a different selected algorithm
* Switching tabs restores the tab's environment and algorithm settings

=== Closing Tabs

* Click the **x** button on the tab
* If the file has unsaved changes, a confirmation dialog appears

== Format Detection

The application automatically detects encrypted values based on the active environment's format:

* Default format: `ENC[encrypted-data]`
* MuleSoft format: `![encrypted-data]`
* Custom formats: As configured in the environment

Encrypted values are displayed with a lock icon in the tree view.

== Tips and Best Practices

=== Password Security

* Use strong, unique passwords for each environment
* Never commit plain-text passwords to version control
* Consider using a password manager for master passwords

=== File Organization

* Keep separate configuration files for each environment
* Use descriptive environment names
* Document which environment was used to encrypt values

=== Workflow

1. Create environments for all your deployment stages
2. Open your configuration file
3. Select the appropriate environment
4. Encrypt sensitive values (passwords, API keys, secrets)
5. Save the file
6. Commit the file with encrypted values to version control

=== KeePass Integration

The application supports KeePass Auto-Type:

* Environment name field is focused when dialog opens
* Press Enter in password field to save
* Press Escape to cancel and close dialog

== Troubleshooting

=== "Decryption failed" Error

* Verify the correct environment is selected
* Check that the master password is correct
* Ensure the algorithm matches the one used for encryption

=== Values Not Detected as Encrypted

* Check the format prefix/suffix matches the encrypted value
* Verify the environment is active (not "No Environment")
* Try re-parsing by making a small edit to the file

=== MuleSoft Password Validation Error

MuleSoft algorithms require passwords of exactly 16 or 32 characters. Adjust your password accordingly.
